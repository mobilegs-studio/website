# Case previews

Screenshots van klantsites voor de portfolio-carousel.

Verwachte bestanden (exacte namen):

- `oreq.png` — screenshot van https://oreq.nl
- `ericsweder.png` — screenshot van https://ericsweder.com

Richtlijnen:

- Liggend formaat, ongeveer 1200x900 of 1280x800.
- De afbeelding wordt `object-cover object-top` getoond, dus de bovenkant
  (hero) van de site is het meest zichtbaar.
- Zolang een bestand ontbreekt valt de carousel automatisch terug op de
  SVG-mockup, dus de site blijft heel.

Koppeling staat in `src/i18n/translations.ts` (veld `image` per story).
